This repository contains my solutions for the **Week 5 Database Assignment** in the PLP Academy Database Systems module. ## 🎯 Learning Objectives
- Manage database indexes to optimize query performance and storage.
- Create and administer database user accounts with host restrictions.
- Assign specific granular privileges (e.g., `INSERT`) to users using Access Control lists.
- Secure database environments by updating user authentication credentials.
